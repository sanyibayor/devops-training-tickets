# DevOps Training Tickets

Team practice repository from a DevOps bootcamp (Landmark Technologies training program). Contains team-completed assignment tickets and one troubleshooting write-up, done while learning core DevOps tooling.

## Contents

- `TICKETS.md` — the full set of training tickets covering Bash scripting, Git/GitHub, Maven, Nexus, Tomcat, Nginx, SonarQube/SonarCloud, Jenkins, and GitHub Actions, with notes and example commands for each.
- `jenkins-url-autoupdate-notes.md` — a short troubleshooting note on auto-updating the Jenkins jenkinsUrl config value on server restart.

## Context

This is coursework, not a production project, kept here as a record of topics covered and hands-on practice with the DevOps toolchain (CI/CD, source control, build tools, code quality scanning, and web/app servers).
